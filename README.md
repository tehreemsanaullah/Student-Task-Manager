# Student Task Manager

A clean, responsive, feature-rich web application built as part of a collaborative Git and web development lab assignment. The application allows students to manage, prioritize, search, and clear tasks locally with a modern user interface.

## 🚀 Features
- **Task Creation:** Add tasks with a custom title, optional description, and a **priority level selector** (Low, Medium, High).
- **Individual Task Deletion:** Remove specific tasks dynamically with an inline delete (`✕`) button.
- **Dynamic Task Counter:** Real-time badge tracking the exact number of active items in the task list.
- **Bulk Clear Action:** Clean up the entire list instantly using the "Clear All Tasks" button (which automatically hides when the list is empty).
- **Real-Time Search Filtering:** Instantly filter through tasks as you type in the search bar.
- **Responsive Layout:** Clean, mobile-friendly card-based design optimized for any screen size.

## 🌿 Git Workflow
This project followed an structured incremental development and branching workflow:
1. **Feature Branching:** Developed discrete features on isolated branches (e.g., `feature/task-search`, priority selection additions).
2. **Incremental Commits:** Performed descriptive, atomic commits for each functional milestone (e.g., core layout, search filter, task count, individual deletion, and priority dropdowns).
3. **Pull Requests (PR):** Integrated feature branches into `main` via Pull Requests, linking relevant issues (e.g., `# Closes issue #2`).
4. **Branch Synchronization:** Managed local and remote divergence using `git pull` and clean merge/reset protocols to maintain a synchronized repository state.

---

## 🌲 Branches
- `main`: The primary production-ready branch containing stable releases.
- `feature/task-search`: Dedicated feature branch utilized for developing and testing the real-time search logic and UI components.
- `feature/task-form`: The first branch that set up the initial HTML code, for the form entry.
- `feature/task-style`: Styling, coloring, alignment and other features for making the application presentable.

## ⚡ Git Commands Demonstrated
Throughout the development of this repository, the following Git commands were utilized:
- `git clone <url>`: To clone the remote repository to the local machine.
- `git status` / `git branch`: To check working tree status and active branches.
- `git add .` / `git commit -m "message"`: To stage and record incremental code changes.
- `git push origin <branch>`: To upload local commits to GitHub.
